# Random Projects With Claude

Petits projets construits avec Claude Code. Chaque dossier est un projet indépendant.

| Dossier | Ce que c'est | Pour le lancer |
| --- | --- | --- |
| `dev-tycoon` | Jeu de gestion : on code seul, on recrute des devs, on leur paie des formations, et on surprend ceux qui trichent avec une IA. | Ouvrir `index.html` |
| `atlas-des-mondes` | Générateur de planètes : climat, biomes, espèces adaptées à leur milieu, peuple et cités. | Ouvrir `index.html` |
| `langues-inventees` | Fabrique de langues : sons, grammaire, écriture, traduction du français et évolution sur 2 000 ans. | Ouvrir `index.html` |
| `erosion-rust` | Simulateur d'érosion en Rust : eau, gel, chimie, vent, glaciers et végétation, avec vingt paramètres. | `cargo run --release` |

Les projets web tournent sans installation ni connexion.

`atlas-des-mondes` et `langues-inventees` vont ensemble : la langue d'une graine est celle du peuple de la planète qui porte la même graine. Les deux dossiers doivent rester côte à côte.
